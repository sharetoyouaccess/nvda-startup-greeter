NVDA Startup Greeter

NVDA Startup Greeter announces that NVDA is ready to use as soon as it starts. By default it speaks a short, time-of-day greeting (“Good morning”, “Good afternoon”, or “Good evening”, followed by “NVDA is ready”), but you can replace it with your own messages – add several, and a different one is spoken each time NVDA starts.

Introduction

NVDA Startup Greeter gives you an instant, spoken confirmation that NVDA is up and running – right after logging in, after NVDA restarts, or after an update. No more wondering whether NVDA has finished loading: as soon as it's ready, you'll hear it. The greeting is designed to speak automatically, right away, with no key press needed.

Features

  • Speaks automatically the moment NVDA is ready to use; no key press required.
  • Time-of-day aware default greeting: Good morning (05:00–11:59), Good afternoon (12:00–17:59), or Good evening (18:00–04:59), followed by “NVDA is ready”.
  • Make it your own: add one or more custom messages to replace the default greeting entirely, from a simple reminder to a personal welcome.
  • Added several messages? A different one is chosen each time NVDA starts, never repeating the one from last time – so it never gets stale.
  • Also shown on a connected braille display, so the confirmation is available whichever way you work.
  • Fully optional: turn the greeting on or off at any time from NVDA Settings.

Settings

This add-on adds an NVDA Startup Greeter category to NVDA's Settings dialog:

  1. Open the NVDA menu and choose Preferences > Settings… (or press NVDA+control+g if you have that gesture assigned).
  2. Select the NVDA Startup Greeter category in the list on the left.
Enable startup announcement
Turns the startup greeting on or off. When unchecked, NVDA stays silent when it starts and the custom message field below is disabled.
Custom messages
Leave this list empty to use the default time-of-day greeting. Use Add… to add a message, select an existing one and use Edit… to change it, or Remove to delete it. If you add more than one message, a different one is spoken each time NVDA starts (the one from last time is never repeated immediately).
